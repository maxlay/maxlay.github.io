雹（Hail）：Android 应用冻结工具

项目地址：https://github.com/aistra0528/Hail

雹是一款自由开源的 Android 应用冻结管理工具（GPL-3.0 协议），核心目标是：
把不常用、常驻后台、耗电唤醒的 App 变成”不可用状态”，需要时再一键恢复。
它不卸载、不删数据，只是让应用暂时跑不起来。

[!IMPORTANT]
我用下来的感受是，真的巨省电！！！

日常最推荐： Android 11+ 用 Shizuku

安装方法

1. 获取安装包

雹不在 Play Store 上架，从以下渠道下载：

  • GitHub Releases：仓库内 Releases 页面下载最新 Hail-*.apk

    https://wget.la/https://github.com/aistra0528/Hail/releases/download/v1.11.0/Hail-v1.11.0.apk

安装时允许”未知来源应用安装”。

2. 推荐方案：Shizuku 模式（无需 Root）

手机端操作：

  1. 安装 Shizuku

    https://wget.la/https://github.com/RikkaApps/Shizuku/releases/download/v13.6.0/shizuku-v13.6.0.r1086.2650830c-release.apk

  2. 进入 开发者选项 → 开启 无线调试（Android 11+）

  3. 打开 Shizuku → 启动服务，确认 Shizuku 在运行

  4. 安装并打开雹 → 设置 → 工作模式 → 选择 Shizuku - Disable / Hide / Suspend

  5. 弹窗授权 Shizuku 给雹

3. 抖音教程：

https://v.douyin.com/4xBmhKZDHRQ/

https://v.douyin.com/-qzlrwwlX1Y/
